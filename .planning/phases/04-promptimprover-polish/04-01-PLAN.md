    Commit message: `ci: add Node 22 GitHub Actions build workflow (PI-02)`

    File content must be EXACTLY:

    ```yaml
    name: CI

    on:
      push:
        branches: [ master ]
      pull_request:

    jobs:
      build-and-test:
        runs-on: ubuntu-latest
        defaults:
          run:
            working-directory: universal-refiner
        steps:
          - uses: actions/checkout@v4

          - name: Setup Node 22
            uses: actions/setup-node@v4
            with:
              node-version: '22'

          - name: Install dependencies
            run: npm ci

          - name: Generate version file
            run: node scripts/sync-version.mjs

          - name: Type check
            run: npx tsc --noEmit

          - name: Run tests
            run: npm test
    ```

    CRITICAL rules:
    - Branch trigger MUST be `master` (not `main`) — Promptimprover default branch is master (NOTE: CONTEXT.md D-02 says "push to main" but RESEARCH.md verified `default_branch: master` via GitHub API; this plan overrides D-02's branch name to use the correct branch)
    - Do NOT include `npm run build` — the build script contains Windows CMD syntax that fails on ubuntu-latest
    - `node scripts/sync-version.mjs` MUST appear BEFORE `npx tsc --noEmit` — generates src/core/generated-version.ts which tsc imports
    - `working-directory: universal-refiner` applies to ALL steps (via defaults.run) — never target mcp-server/
    - No `npm run build` step anywhere in the workflow
